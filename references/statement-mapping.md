# 科目余额表 → 报表项目映射

> 用于「财务报表编制」与「财务分析」。科目名以企业会计准则通用科目为准，企业自定义科目按经济实质归类。

## 一、资产负债表

| 报表项目 | 取数科目 |
|---|---|

| 其他应收款 | 其他应收款 − 坏账准备 + 应收利息 + 应收股利 |
| 存货 | 原材料 + 在产品 + 库存商品 + 发出商品 + 周转材料 − 存货跌价准备 |

## 二、利润表

| 报表项目 | 计算 |
|---|---|

| 税金及附加 | 税金及附加 |

| 其他收益 | 其他收益（政府补助等） |

| 信用减值损失 | 信用减值损失（损失以"−"列示） |
| 资产减值损失 | 资产减值损失（损失以"−"列示） |
| 资产处置收益 | 资产处置损益 |

## 三、现金流量表（间接法起点）

| 项目 | 取数 |
|---|---|
| 净利润 | 利润表 |
| 加：资产减值准备 | 信用 + 资产减值损失 |
| 固定资产折旧 | 累计折旧本期贷方发生额（剔除处置转出） |
| 无形资产摊销 | 累计摊销本期贷方发生额 |
| 使用权资产折旧 | 对应累计折旧 |
| 长期待摊费用摊销 | 本期摊销额 |
| 处置资产损失（收益以"−"） | 资产处置损益 |
| 财务费用 | 剔除经营相关部分后的筹资性利息 |
| 存货减少（增加以"−"） | 期末 − 期初 |
| 经营性应收减少 | 应收票据 + 应收账款 + 预付款项 + 其他应收款 变动 |
| 经营性应付增加 | 应付票据 + 应付账款 + 合同负债 + 应付职工薪酬 + 应交税费 变动 |

## 四、勾稽校验清单

编完三表必须过这九项，**任一不平不得出分析结论**：

1. 资产总计 = 负债合计 + 所有者权益合计
2. 利润表净利润 = 资产负债表未分配利润变动（剔除分配与调整）
3. 现金流量表期末现金余额 = 资产负债表货币资金
4. 现金流量表净利润起点 = 利润表净利润
5. 本期计提折旧摊销 = 累计折旧/摊销贷方发生额（剔除处置）
6. 所得税费用 = 当期所得税 + 递延所得税变动
7. 各报表小计 = 明细项之和
8. 本期期初数 = 上期期末数
9. 所有者权益变动表各栏合计 = 资产负债表对应项目变动
