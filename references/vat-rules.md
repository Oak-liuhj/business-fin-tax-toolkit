# 增值税口径与申报

> **税率、征收率、优惠政策随年度调整**。本文件给机制与计算方法，具体税率须核对当期有效文件；无法确认时输出标注"待核当期文件"，不得凭记忆断言。

## 一、纳税人身份

| 类型 | 判定 | 计税方法 |
|---|---|---|
| 一般纳税人 | 年应税销售额超标准或主动登记 | 一般计税（销项 − 进项），特定情形可选简易计税 |
| 小规模纳税人 | 未超标准 | 简易计税，征收率 3%（优惠期待核），季度销售额未超限额可免征 |

## 二、税率档位（机制说明）

- **13%**：销售货物、加工修理修配劳务、有形动产租赁、进口货物
- **9%**：交通运输、邮政、基础电信、建筑、不动产租赁与销售、农产品、自来水/暖气/燃气等
- **6%**：现代服务、生活服务、金融、无形资产（技术转让等除外）
- **0%**：出口货物、跨境应税行为（适用退免税）
- 兼营与混合销售：分别核算，未分别核算从高适用

## 三、销项税额

```
销项税额 = 不含税销售额 × 适用税率
不含税销售额 = 含税销售额 ÷ (1 + 适用税率)
```

视同销售情形：将货物用于捐赠、投资、分配给股东、无偿赠送、用于集体福利或个人消费（自产货物）等。

**纳税义务发生时间**：先开票的为开票当天；否则为收到销售款或取得索取销售款凭据当天；赊销按合同约定收款日；预收货款（生产工期超 12 个月的大型设备等）按约定。

## 四、进项税额与抵扣限制

可抵扣：取得合规增值税专用发票、海关缴款书、农产品收购发票/销售发票、完税凭证。

**不得抵扣**：
- 用于简易计税、免税项目、集体福利、个人消费的购进
- 非正常损失（管理不善造成的被盗、丢失、霉烂变质）
- 业务招待费
- 贷款服务的进项税（按现行规定不得抵扣，须核对当期文件）

**转出**：已抵扣后改变用途、发生非正常损失的，按公式转出。

## 五、出口退税（免抵退，生产企业）

步骤：

1. **免**：出口销售环节免征增值税。
2. **抵**：出口货物对应的进项税额抵减内销应纳税额。
3. **退**：未抵完的部分按规定退税率计算退税。

```
当期应纳税额 = 内销销项 − (当期进项 − 当期免抵退税额不得免征和抵扣税额)
免抵退税额不得免征和抵扣税额 = 出口离岸价 × (征税率 − 退税率)
当期免抵退税额 = 出口离岸价 × 退税率
应退税额 = min(期末留抵税额, 当期免抵退税额)
免抵税额 = 当期免抵退税额 − 应退税额
```

- 外贸企业适用**免退税**：应退税额 = 购进金额 × 退税率。
- 需在申报期内完成出口退（免）税申报，逾期后果及补申报条件须按所属期、单证和有效文件核验，不一概认定为内销征税。
- **退税率须核对当期出口退税率文库**。

## 六、加计抵减（机制，比例须核当期文件）

适用行业、资格与有效期按具体政策登记；不得将历史生产/生活性服务业范围直接当作当前适用条件。按确认后的可抵扣进项税额及比例试算。要点：

- 加计抵减额**不改变进项税额本身**，只减少应纳税额；
- 只能抵减一般计税项目的应纳税额，不能抵减简易计税；
- 需单独核算并留存计算表；
- 政策有适用期限，**必须核对当期文件确认比例与有效期**，不得套用旧比例。

## 七、申报底稿结构

一份完整底稿包含：

1. **销项明细表**：开票明细（含作废、红冲）+ 未开票收入 + 视同销售
2. **进项明细表**：认证/勾选清单 + 转出清单 + 不得抵扣清单
3. **进销项匹配表**：按客户/供应商/商品维度匹配，标出长期零销项有进项、进销项严重倒挂、大额顶额开票等异常
4. **税负测算表**：本期税负率、近 12 个月移动平均、同行业参考区间
5. **附表勾稽**：主表与附表一/二/四数据一致性
6. **风险清单**：逐条列异常指标、可能原因、建议动作

## 八、常见异常预警指标

| 指标 | 异常信号 | 可能原因 |
|---|---|---|
| 增值税税负率 | 显著低于行业均值 | 少计销项、虚抵进项、大量留抵 |
| 进销项比 | 长期进大于销 | 存货积压、虚假采购 |
| 开票集中度 | 月末集中顶额开票 | 人为调节 |
| 作废/红冲率 | 高于 5% | 开票不规范或虚开 |
| 免税销售额占比 | 突增 | 政策适用错误 |
| 留抵税额 | 长期大额留抵且无退税申请 | 应享未享或虚构进项 |

> 上述阈值为经验参考，须结合行业与企业规模判断，不作为定性结论。

## 九、输出措辞要求

- 只写"测算结果 + 风险等级（高/中/低）+ 建议复核项"
- 不写"可以这样申报""没有问题"
- 涉及具体政策条款时注明文号；记不清文号就说"具体文号待核"
