# CAS 准则口径速查

> 适用范围：企业会计准则（CAS）。文中税率、比例、门槛**均有政策时效**，使用时须核对当期有效文件；无法确认时在输出中标注"待核当期文件"。

## 一、会计要素与计量

- 资产 = 负债 + 所有者权益；收入 - 费用 = 利润。
- 计量属性：历史成本（默认）、重置成本、可变现净值、现值、公允价值。
- **公允价值使用须有层级说明**（活跃市场报价 / 可观察输入 / 不可观察输入），第三层级要披露估值方法。

## 二、常见业务判断

### 收入确认（CAS 14，五步法）
1. 识别与客户订立的合同；
2. 识别合同中的单项履约义务；
3. 确定交易价格（含可变对价、重大融资成分、非现金对价、应付客户对价）；
4. 分摊交易价格至各履约义务（按单独售价相对比例）；
5. 履行履约义务时确认收入（时点 or 时段）。

- **时段确认三条件**之一：客户在企业履约同时取得并消耗经济利益；客户能控制在建商品；产出不可替代且企业有权就累计已完成部分收款。
- 可变对价：计入交易价格的金额以"极可能不会发生重大转回"为限。
- 主要责任人 vs 代理人：控制权判断，决定总额法/净额法。

### 租赁（CAS 21）
- 承租人不区分融资/经营租赁，统一确认**使用权资产**与**租赁负债**（短期租赁 ≤12 个月、低价值资产可豁免，按直线法）。
- 折现率：租赁内含利率优先，无法确定时用增量借款利率。
- 出租人仍区分融资租赁与经营租赁。

### 金融工具（CAS 22/23/24）
- 三分类：以摊余成本计量、以公允价值计量且变动计入其他综合收益（FVOCI）、以公允价值计量且变动计入当期损益（FVTPL）。
- 分类依据：**业务模式 + 合同现金流量特征**（SPPI 测试）。
- 预期信用损失（ECL）三阶段模型，不得用"未发生即不计提"。

### 研发支出
资本化**五项条件同时满足**：
1. 完成该无形资产以使其能使用或出售在技术上具有可行性；
2. 具有完成该无形资产并使用或出售的意图；
3. 能证明无形资产产生经济利益的方式；
4. 有足够的技术、财务资源和其他资源支持完成开发；
5. 归属于该无形资产开发阶段的支出能够可靠地计量。

研究阶段支出全部费用化；开发阶段满足条件才资本化。**资本化时点必须有立项、评审、工时与领料证据链**。

### 政府补助（CAS 16）
- 与资产相关：冲减资产账面价值或确认递延收益分期计入损益。
- 与收益相关：补偿以后期间 → 递延收益；补偿已发生 → 直接计入当期损益或冲减成本费用。

### 存货与减值
- 存货期末按成本与可变现净值孰低计量。
- 资产减值（CAS 8）：可收回金额 = 公允价值减处置费用 与 预计未来现金流量现值 孰高；**一经计提不得转回**（存货、应收、金融资产除外）。

### 合并范围（CAS 33）
- 以**控制**为基础：权力 + 可变回报 + 运用权力影响回报。
- 持股比例不是唯一标准；一致行动、表决权委托、潜在表决权都要看。

## 三、常见易错点

| 易错点 | 正确做法 |
|---|---|
| 把研究阶段支出资本化 | 研究阶段一律费用化 |
| 收入按开票时点确认 | 按履约义务完成（控制权转移）时点 |
| 短期租赁也确认使用权资产 | ≤12 个月可豁免 |
| 资产减值准备随意转回 | 长期资产减值不得转回 |
| 合并只按持股比例 | 按控制判断，含结构化主体 |

## 四、输出时的口径声明模板

```
会计准则：企业会计准则（CAS）
适用期间：2026 年度
金额单位：元（或万元，须全文统一）
口径：单体 / 合并
政策时效：税率与限额按 XX 号文，如与当期文件不符以当期为准
```
