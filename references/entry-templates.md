# 凭证编制参考 · 标准分录模板库

> 内部参考知识，由「做凭证」子技能调用；也可单独查询。所有分录为**标准情形**，实际业务须结合合同、发票、单据判断。税率按常见档位列示，使用时核对当期税率。

## 编制规范

1. **一借一贷或多借多贷**，金额平衡；一张凭证只记一类业务。
2. 摘要写清"谁 + 什么 + 期间"，不写"费用""往来"这种无信息量的词。
3. 附件齐全：发票（或合规凭证）、合同/订单、验收单/入库单、付款回单。
4. 科目用到底级，辅助核算（部门/项目/客户/供应商）必须填。
5. 外币业务同时记录原币、汇率、本位币；汇率来源注明（月初/当日中间价/银行成交价）。

## 一、采购与应付

### 采购存货（一般纳税人，取得专票）
```
借：原材料 / 库存商品            不含税金额
    应交税费—应交增值税（进项税额）  税额
  贷：应付账款—XX 供应商            价税合计
```

### 采购固定资产
```
借：固定资产                      不含税金额
    应交税费—应交增值税（进项税额）  税额
  贷：银行存款 / 应付账款
```
> 一次性税前扣除是**税务处理**，会计上仍按折旧年限计提，差异通过汇算清缴调整。

### 预付货款
```
借：预付账款—XX 供应商
  贷：银行存款
```

### 暂估入库（月末货到票未到）
```
借：原材料
  贷：应付账款—暂估应付款
```
次月初红字冲回，票到后按实际入账。

## 二、费用类

### 管理费用 / 销售费用（取得专票）
```
借：管理费用—办公费 / 销售费用—业务招待费   不含税金额
    应交税费—应交增值税（进项税额）          税额（招待费不得抵扣，见下）
  贷：银行存款
```
> **业务招待费、集体福利、个人消费的进项税不得抵扣**，全额计入费用。

### 职工薪酬（计提与发放）
```
计提：
借：管理费用/销售费用/生产成本—职工薪酬
  贷：应付职工薪酬—工资
      应付职工薪酬—社保（单位部分）
      应付职工薪酬—住房公积金（单位部分）

发放：
借：应付职工薪酬—工资
  贷：银行存款
      应交税费—应交个人所得税
      其他应付款—社保（个人部分）
```

### 折旧与摊销
```
借：管理费用/制造费用—折旧费
  贷：累计折旧

借：管理费用—无形资产摊销
  贷：累计摊销
```

## 三、收入与应收

### 销售商品（时点确认）
```
借：应收账款—XX 客户              价税合计
  贷：主营业务收入                  不含税金额
      应交税费—应交增值税（销项税额）  税额

结转成本：
借：主营业务成本
  贷：库存商品
```

### 预收货款
```
借：银行存款
  贷：合同负债
```
履约后转入收入并确认销项税。

### 计提坏账（预期信用损失）
```
借：信用减值损失
  贷：坏账准备
```

## 四、税费

### 月末结转增值税
```
借：应交税费—应交增值税（转出未交增值税）
  贷：应交税费—未交增值税
```
（进项大于销项时反向，形成留抵，不结转）

### 计提附加税费
```
借：税金及附加
  贷：应交税费—应交城市维护建设税
      应交税费—应交教育费附加
      应交税费—应交地方教育附加
```

### 计提企业所得税
```
借：所得税费用
  贷：应交税费—应交企业所得税
```

### 印花税、房产税、土地使用税
```
借：税金及附加
  贷：应交税费—印花税 / 房产税 / 土地使用税
```

## 五、外币业务

### 外币收款（收到美元货款）
```
借：银行存款—美元户（原币 × 即期汇率）   本位币
  贷：应收账款—XX 客户（原账面本位币）
      财务费用—汇兑损益（差额，可借可贷）
```

### 期末外币货币性项目折算
```
借：财务费用—汇兑损益
  贷：银行存款—美元户 / 应收账款
```
（汇率上升则反向）

> 外币非货币性项目（如以历史成本计量的存货、固定资产）期末**不重新折算**。

## 六、研发支出

### 费用化阶段
```
借：研发支出—费用化支出
  贷：银行存款 / 应付职工薪酬 / 原材料
月末：
借：管理费用—研发费用
  贷：研发支出—费用化支出
```

### 资本化阶段
```
借：研发支出—资本化支出
  贷：银行存款 / 应付职工薪酬 / 原材料
达到预定用途：
借：无形资产
  贷：研发支出—资本化支出
```

## 七、制造业成本核算

### 领用材料
```
借：生产成本—直接材料
  贷：原材料
```

### 分配人工与制造费用
```
借：生产成本—直接人工
    制造费用
  贷：应付职工薪酬 / 累计折旧 / 银行存款
```

### 结转完工产品
```
借：库存商品
  贷：生产成本—直接材料/直接人工/制造费用
```

### 销售成本结转
```
借：主营业务成本
  贷：库存商品
```

## 八、年末结转

### 结转本年利润
```
借：主营业务收入 / 其他业务收入 / 营业外收入 / 投资收益 / 公允价值变动收益
  贷：本年利润

借：本年利润
  贷：主营业务成本 / 税金及附加 / 销售费用 / 管理费用 / 研发费用 /
      财务费用 / 营业外支出 / 所得税费用 / 信用减值损失 / 资产减值损失
```

### 结转利润分配
```
借：本年利润
  贷：利润分配—未分配利润
（亏损反向）

借：利润分配—提取法定盈余公积
  贷：盈余公积—法定盈余公积

借：利润分配—应付现金股利
  贷：应付股利
```

## 九、常见错误对照

| 错误做法 | 正确做法 |
|---|---|
| 招待费进项税抵扣了 | 不得抵扣，全额入费用 |
| 一次性税前扣除直接冲减固定资产 | 会计照常折旧，税会差异年度调整 |
| 预收款直接确认收入 | 先记合同负债，履约后确认 |
| 汇兑差额计入资本公积 | 计入财务费用—汇兑损益 |
| 研发支出全部资本化 | 研究阶段费用化，开发阶段满足五项条件才资本化 |
| 暂估入库跨年不冲回 | 次月初冲回，票到按实际入账 |
