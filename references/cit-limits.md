# 企业所得税 · 扣除限额与纳税调整

> **以下税率、比例、期限均有适用年度与文件依据**。给测算时必须在结论中标注"按 XX 年度口径，需核对当期文件"。记不清文号就写"文号待核"，不要编造。

## 一、税率

| 情形 | 税率 |
|---|---|
| 一般企业 | 25% |
| 国家需要重点扶持的高新技术企业 | 15% |
| 小型微利企业 | 优惠计算（应纳税所得额、从业人数、资产总额三项同时满足；具体优惠幅度按当期文件） |
| 西部大开发鼓励类 | 15% |
| 技术先进型服务企业 | 15% |

## 二、常见扣除限额

| 项目 | 限额 | 依据口径 |
|---|---|---|
| 业务招待费 | 发生额 60% 与当年销售（营业）收入 5‰ **孰低** | 超支永久性差异，不结转 |
| 广告费和业务宣传费 | 一般企业营业收入 15% | 超支可结转以后年度；化妆品制造/医药制造/饮料制造（不含酒类）30% |
| 职工福利费 | 工资薪金总额 14% | 超支不得扣除，不结转 |
| 工会经费 | 工资薪金总额 2% | 需取得工会经费收入专用收据 |
| 职工教育经费 | 工资薪金总额 8% | 超支可结转以后年度 |
| 补充养老保险 / 补充医疗保险 | 工资薪金总额各 5% | 需符合国家规定范围与标准 |
| 公益性捐赠 | 年度利润总额 12% | 超支可结转 3 年；特定事项（扶贫、疫情等）可能全额扣除，按当期文件 |
| 手续费及佣金 | 一般企业合同金额 5% | 保险企业另有比例 |
| 党组织工作经费 | 工资薪金总额 1% | 纳入管理费用 |
| 研发费用加计扣除 | 费用化部分按实际发生额加计（比例按当期文件，制造业与科技型中小企业通常更高）；资本化部分按无形资产成本加计摊销 | **烟草、住宿餐饮、批发零售、房地产、租赁商务服务、娱乐业不适用**；需留存备查资料 |
| 亏损结转 | 一般 5 年；高新、科技型中小企业 10 年 | 境外亏损不得抵减境内所得 |

## 三、常见纳税调整项

### 调增
1. 超过限额的招待费、广告费、福利费、教育经费、捐赠
2. 税收滞纳金、罚金、罚款（行政罚款；**经营性违约金可扣除**）
3. 与生产经营无关的支出、赞助支出
4. 未经核定的准备金（坏账准备、存货跌价准备等，除金融企业按规定的）
5. 不征税收入形成的费用（已作不征税处理的财政性资金所发生的支出）
6. 职工个人消费性支出记入公司成本
7. 关联交易不符合独立交易原则的部分

### 调减
1. 国债利息收入、符合条件的居民企业间股息红利
2. 研发费用加计扣除
3. 安置残疾人员工资加计
4. 以前年度超限额结转的广告费、教育经费
5. 符合条件的创业投资抵扣应纳税所得额
6. 综合利用资源减计收入

## 四、专项场景

### 股权激励
- 上市公司：等待期内会计确认的成本费用，**税法上不得扣除**，需纳税调增；实际行权/解禁时按公允价格与行权价差额确认工资薪金支出，可税前扣除并作调减。
- 非上市公司：符合条件的可递延纳税（财税〔2016〕101 号），需备案。
- 关键：**会计费用与税前扣除存在时间性差异**，需建递延所得税台账逐年跟踪。

### 资产损失
- 分**清单申报**（正常销售、转让、报废、毁损等）与**专项申报**（坏账损失、被盗、自然灾害等）。
- 需留存证据：合同、判决书、破产清算公告、资产盘点表、责任人赔偿说明、中介机构报告。
- 会计已计提减值但未实际发生损失的，不得税前扣除，作调增。

### 境外所得
- 分国不分项（或按规定选择不分国不分项）计算抵免限额：
  ```
  抵免限额 = 中国境内外所得按税法计算的应纳税总额 × 来源于某国的应纳税所得额 ÷ 境内外应纳税所得总额
  ```
- 超过限额部分可在 5 年内结转抵免；需提供境外税务机关出具的完税证明。

### 债务重组
- 债务人：以非货币资产清偿的，分解为按公允价值转让资产 + 清偿债务两步，确认资产转让所得；债务重组所得计入应纳税所得额，符合条件可分 5 年均匀计入。

## 五、申报底稿结构

1. **利润总额调节表**：会计利润 → 纳税调整 → 应纳税所得额
2. **调整明细表**：逐项列"项目 / 会计金额 / 税法金额 / 调整额 / 调整类型（永久/暂时）/ 依据"
3. **限额校验表**：每个限额项目列"基数 / 限额比例 / 限额 / 实际发生 / 可扣除 / 结转或调增"
4. **亏损弥补表**：各年度可弥补亏损余额与本年弥补额
5. **优惠事项表**：享受的优惠、依据文件、留存备查资料清单
6. **风险等级表**：每项调整标"高/中/低"风险与建议复核动作

## 六、措辞红线

- 写"测算应纳税所得额为 X，调整项如下"，不写"申报这个数就行"
- 写"该处理存在被调整风险，建议与主管税务机关沟通或由执业机构出具意见"
- 不替用户决定会计政策或优惠适用，只呈现可选方案与后果
