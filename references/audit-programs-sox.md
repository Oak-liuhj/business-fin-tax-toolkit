# 内部审计 · 程序库与 SOX/IFRS 适配

## 一、审计程序基本结构

每个循环的底稿都按同一骨架写，保证可复核：

```
1. 循环描述与关键风险
2. 控制点清单（控制目标 / 控制活动 / 责任人 / 频率 / 类型：预防性|检查性）
3. 测试程序（穿行测试 / 控制测试 / 实质性测试）
4. 抽样方法与样本量
5. 测试结果与偏差
6. 发现与评级
7. 管理层回复与整改计划
```

**样本量参考**（控制测试，日频/高频控制）：年度发生次数 >250 取 25 个；50–250 取 15 个；<50 取 5–10 个或全部。低频（月度）取 2–3 个，季度取 2 个。抽样方法优先**随机 + 重点项结合**，不只看大额。

## 二、六大业务循环程序

### 1. 采购到付款（P2P）
风险：虚构供应商、串通舞弊、重复付款、未记录负债。
程序：
- 供应商主数据变更审批抽查（重点：银行账号变更）
- 采购申请 → 订单 → 入库 → 发票 → 付款 **五单匹配**测试
- 三单不符、无订单付款、付款账户与合同不一致的全量筛查
- 期末未入账负债（cut-off）测试：查期后付款与期前收货
- 供应商与员工/关联方重名、同地址、同电话筛查

### 2. 销售到收款（O2C）
风险：虚构收入、提前确认、坏账低估、返利未计提。
程序：
- 收入确认时点测试（对照合同履约义务与验收单）
- 期末大额销售退回与期后红冲筛查
- 应收账款账龄与回款率分析，超期客户单项评估
- 关联方销售定价公允性
- 销售返利、折扣、返点的计提完整性

### 3. 存货到成本（I2C）
风险：存货虚增、成本结转错误、跌价准备不足。
程序：
- 存货监盘（抽盘比例、呆滞品识别、第三方存放函证）
- 成本核算方法一致性检查（加权平均/先进先出，是否中途变更）
- 在产品完工程度与约当产量合理性
- 单位成本环比异常波动分析
- 跌价准备测试：可变现净值取价依据

### 4. 薪酬与人事（H2R）
风险：幽灵员工、虚发工资、社保基数不实。
程序：
- 花名册与工资表、社保申报、个税申报四方比对
- 离职人员工资延续发放筛查
- 银行代发账户与员工本人一致性抽样
- 加班费、奖金审批链完整性

### 5. 资金与银行（T2B）
风险：资金挪用、未披露受限资金、体外循环。
程序：
- 全部银行账户完整性确认（人民银行账户查询/函证）
- 银行余额调节表编制与复核（未达账项超 30 天的逐笔说明）
- 大额与异常资金往来全量筛查（整数金额、夜间、节假日、同一天进出）
- 受限资金（保证金、质押、冻结）披露完整性
- 网银 U 盾/密钥分离保管检查

### 6. 固定资产与在建工程（F2R）
风险：资产虚增、资本化范围不当、闲置未减值。
程序：
- 实地盘点与台账核对，标签管理检查
- 在建工程转固时点测试（是否已达到预定可使用状态）
- 利息资本化计算复核
- 闲置/停用资产减值测试
- 处置审批与收入确认

## 三、数据分析审计（全量而非抽样）

优先用全量数据分析替代抽样，输出"异常清单 + 判定依据"：

| 分析类型 | 具体做法 |
|---|---|
| 重复付款 | 同供应商 + 同金额 + 时间窗内多次付款 |
| 整数金额 | 大额整数付款占比异常 |
| 幽灵供应商 | 供应商注册地址/电话/银行账户与员工重合 |
| 异常时点 | 节假日、夜间、期末最后 3 天的交易 |
| 单一来源 | 无招标记录的供应商集中度 |
| 期末异动 | 应收/存货/收入在期末前 5 天突增 |
| Benford 定律 | 金额首位数字分布偏离（仅作线索，不定性） |

**每条线索必须写"可能解释"**，避免把正常业务定性为问题。

## 四、SOX 404 适配

### 控制层级
- **公司层面控制（ELC）**：治理结构、道德与合规、风险评估、集中处理
- **业务流程控制（ITAC + 手工控制）**：上述六循环
- **IT 一般控制（ITGC）**：访问管理、变更管理、运维管理、程序开发

### ITGC 必查项
1. 离职员工账号是否及时停用（抽查离职清单 vs 系统账号停用时间）
2. 特权账号（root/管理员/SA）清单与使用日志
3. 生产环境变更是否有审批、测试、回滚方案
4. 直连生产数据库修改数据的审批与留痕
5. 备份恢复演练记录

### 缺陷分级
- **重大缺陷（Material Weakness）**：可能导致财务报表重大错报且未被及时防止或发现
- **重要缺陷（Significant Deficiency）**：低于重大缺陷但足以引起关注
- **一般缺陷**：其他

不定性为"重大缺陷"前，必须评估**补偿性控制**是否存在并有效。

## 五、CAS 与 IFRS 主要差异（影响审计判断的部分）

| 事项 | CAS | IFRS |
|---|---|---|
| 资产减值转回 | 长期资产减值不得转回 | 允许转回（商誉除外） |
| 存货计价 | 不允许后进先出 | 同样不允许（IAS 2） |
| 开发支出 | 满足条件可资本化 | 满足条件**必须**资本化 |
| 政府补助 | 总额法/净额法可选 | 类似，但披露要求更细 |
| 关联方披露 | 范围较窄 | 范围更宽（含关键管理人员近亲属） |
| 持有待售 | 单独准则 | IFRS 5，计量与列报更严 |
| 租赁 | 承租人单一模型 | IFRS 16 类似 |
| 合并 | 控制模型 | IFRS 10 控制模型，判断要素表述不同 |

**做 SOX/IFRS 项目时，先确认报告目的与准则版本**，不要默认套 CAS。

## 六、发现报告结构

```
一、审计概况（范围、期间、方法、样本量）
二、总体结论（一句话：控制是否有效）
三、发现清单
    3.1 问题描述（事实，不含推测）
    3.2 影响（金额或范围，量化优先）
    3.3 根本原因（流程/系统/人）
    3.4 风险评级（高/中/低 + 判定依据）
    3.5 建议（可执行、有责任人、有期限）
四、管理层回复
五、整改跟踪表
```

**只写事实与可验证的推断**。推测性表述必须标"待核实"。
