# 核算与月结（凭证与关账）

本手册二合一：**卷一 · 凭证编制**（日常做账），**卷二 · 月结管理**（月末关账）。两者是同一条核算链的上下游：日常分录构成账簿，月结把账簿收口成可出表的余额。

**分流规则**：用户问"这笔怎么做账 / 分录怎么写 / 凭证怎么编" → 卷一；提到"月结 / 关账 / 计提清单 / 成本核算 / 关账检查表" → 卷二；关账过程中的任何计提与结转分录，一律按卷一的模板与摘要规范落。

# 卷一：凭证编制（bookkeeping-voucher）

## 何时触发

用户贴一段业务描述、一张发票信息、或问"这笔怎么做账""分录怎么写"。

## 需要什么输入

**必需**：业务事实（谁、和谁、什么事、金额、含税还是不含税、日期）。
**按业务补充**：发票类型（专票/普票/其他）、合同条款（收款/履约时点）、纳税人身份（一般/小规模）、外币原币金额与汇率、是否已付款。

**信息不足时不要猜**，直接列出"缺失信息 → 影响的分录处理"，让用户补。典型缺口：
- 含税/不含税不明 → 影响税金拆分
- 一般/小规模不明 → 影响能否抵扣
- 履约时点不明 → 影响收入确认时点

## 编制步骤

### 第一步：识别业务类型
归入：采购存货 / 采购固定资产 / 费用支出 / 职工薪酬 / 销售收款 / 预收预付 / 税费 / 外币 / 研发 / 成本结转 / 年末结转 / 其他。

### 第二步：匹配模板
从 `references/entry-templates.md` 取对应模板，按实际调整科目明细与辅助核算。涉及计量口径、确认时点、会计政策或差错更正拿不准时，查 `references/cas-basics.md`，并在输出里写明所依据的准则条款名称。

### 第三步：确认五个细节

1. **票据合规**：专票才可抵扣；普票、收据、白条不得抵扣，且部分支出不得税前扣除。
2. **不得抵扣情形**：业务招待、集体福利、个人消费、简易计税与免税项目、非正常损失。
3. **税前扣除限制**：招待费（60% 且 ≤ 收入 5‰）、福利费 14%、教育经费 8% 等，超额部分要提示"汇算清缴需调整"。
4. **时点**：收入按履约义务完成（控制权转移），不按开票；费用按权责发生制，跨期要预提或待摊。
5. **资本化 vs 费用化**：固定资产达到预定可使用状态即转固；研发按阶段判定。

### 第四步：写摘要
格式：`<对方/事项> + <业务性质> + <期间>`
好例子：`采购 A 材料 3 月货款（已验收）`、`计提 2026 年 3 月工资及社保`。
坏例子：`费用`、`付款`、`往来`。

### 第五步：列附件
发票 / 合同或订单 / 验收单或入库单 / 付款回单 / 审批单 / 计算表（折旧、摊销、工资、税费）。

## 重点场景处理

### 外币业务
- 交易日用**即期汇率或近似汇率**（当月平均），一经选定前后一致。
- 期末货币性项目按期末汇率折算，差额入 `财务费用—汇兑损益`。
- 非货币性项目（历史成本计量的存货、固定资产）期末**不再折算**。
- 输出同时给原币、汇率、本位币三列，汇率来源写清楚（中间价/银行成交价/月初）。

### 研发支出
- 研究阶段、以及开发阶段不满足五项条件的：全部费用化，月末转 `管理费用—研发费用`。
- 满足资本化的：挂 `研发支出—资本化支出`，达预定用途转 `无形资产`。
- **资本化必须有证据链**：立项文件、阶段评审记录、工时记录、领料单。缺证据不要资本化，直接提示风险。

### 制造业成本
- 直接材料、直接人工计入 `生产成本`；间接费用先归集 `制造费用`，按合理标准（工时、机时、产量）分配。
- 完工转 `库存商品`，销售转 `主营业务成本`。
- 在产品约当产量法要说明完工程度依据。
- 成本核算方法（加权平均/先进先出/分批/分步）一经选定不得随意变更，变更要披露。
- 完整成本核算流程（归集→分配→约当产量→单位成本）见**卷二·制造业成本核算**，本卷只写分录层。

### 税费
- 月末结转未交增值税、计提附加税费、计提企业所得税。
- 附加税费按实际缴纳的增值税与消费税合计为基数。
- 印花税、房产税、土地使用税计入 `税金及附加`。
- 月末这一组动作在**卷二第 6-7 步**有完整清单与顺序，关账时按卷二执行、按本卷写分录。

### 年末结转
- 损益类科目全部转 `本年利润`，再转 `利润分配—未分配利润`。
- 提取法定盈余公积（累计达注册资本 50% 可不再提）。
- 分配股利走 `利润分配—应付现金股利` → `应付股利`。
- 日常月份只做损益结转的简化口径（卷二第 8 步）；年末全量结转按本节。

## 输出模板

```
一、业务判断（一句话说清这笔是什么、按什么原则处理）
二、会计分录
    借：科目—明细（辅助核算）      金额
      贷：科目—明细（辅助核算）    金额
    摘要：...
三、附件清单
四、税务提示（能否抵扣 / 税前扣除限额 / 需汇算调整的部分）
五、待确认事项（信息缺口与影响）
```

多笔业务用表格批量输出：

| 序号 | 日期 | 摘要 | 借方科目 | 贷方科目 | 金额 | 附件 |
|---|---|---|---|---|---|---|

## 卷一自检清单

- [ ] 借贷平衡，金额与单据一致
- [ ] 科目用到末级，辅助核算齐全
- [ ] 含税/不含税已拆分，税率正确
- [ ] 不得抵扣的进项没有抵扣
- [ ] 摘要能让人看明白发生了什么
- [ ] 附件清单完整
- [ ] 收入时点符合履约义务，不是按开票
- [ ] 资本化有证据链，否则已费用化并提示
- [ ] 外币三要素（原币、汇率、本位币）齐全
- [ ] 缺失信息已列出，没有暗中假设

# 卷二：月结管理（month-end-close）

## 何时触发

用户要安排月末结账、写关账 SOP、检查关账是否漏项，或问"制造业成本怎么算"。

## 需要什么输入

**必需**：结账期间、主体范围、行业（是否制造业）、现有结账日与出表日要求。
**建议**：现行科目表、成本核算方法、上期关账问题清单。

## 十步关账清单

### 第 1 步：业务截止（Cut-off）
- 通知各部门单据截止时间（采购入库、报销、销售发货）
- 最后一天交易单独标记，跨期单据按权责发生制归属
- 检查期后收货/发货，避免跨期
- **系统关账前必须锁定当月凭证录入权限**

### 第 2 步：银行与资金
- 全部银行账户对账单下载，编制余额调节表
- 未达账项逐笔说明，超 30 天的重点核查
- 现金盘点，备用金核对
- 受限资金（保证金、冻结）标注，供报表披露

### 第 3 步：往来核对
- 应收/应付/其他应收应付明细账龄更新
- 与主要客户、供应商对账，差异挂"待查"
- 关联方往来单独核对
- 预收/预付按履约进度转入收入/成本

### 第 4 步：存货与成本
- 出入库单据全部过账，检查负库存
- 存货盘点（月盘或抽盘），差异调整
- 采购暂估入账（货到票未到），次月初冲回
- 制造业成本核算（见下）
- 存货跌价测试

### 第 5 步：固定资产与无形资产
- 新增资产转固（达到预定可使用状态即转，不以验收款付清为准）
- 在建工程检查，长期不转固的说明原因
- 计提折旧与摊销（注意当月新增下月计提的规则）
- 处置资产清理，净值与累计折旧同步转出

### 第 6 步：计提与摊销
必查清单：
- 职工薪酬（工资、奖金、社保、公积金、个税）
- 折旧、摊销、长期待摊费用
- 利息（含未到付息日的应计利息）、借款费用资本化
- 租金、水电、物业、审计费等已发生未取得发票的
- 销售返利、折扣、质保金
- 坏账准备（预期信用损失）
- 应交税费（增值税结转、附加税费、企业所得税、印花税、房产税）
- 预计负债（诉讼、保修）

以上每一项的分录写法与摘要规范按**卷一**执行。

### 第 7 步：税费
```
1. 销项与进项核对，进项转出处理
2. 结转未交增值税：借 应交税费—转出未交增值税 / 贷 未交增值税
3. 计提附加税费（以实缴增值税+消费税为基数）
4. 计提企业所得税（按当期利润与调整测算）
5. 印花税、房产税、土地使用税计提
```
销项进项核对与税负口径详见 `skills/tax-compliance/SKILL.md` 增值税卷。

### 第 8 步：损益结转与试算平衡
- 损益类科目转本年利润
- 试算平衡：借贷合计相等；期初 + 发生 = 期末
- 科目余额表导出，异常余额排查（如资产类出现贷方余额）

### 第 9 步：出表与勾稽
按 `skills/statements-analysis/SKILL.md` 卷一出三表，跑九项勾稽。**不平不出表**。

### 第 10 步：复核与归档
- 关键科目变动分析（环比 >30% 要说明）
- 关账检查表逐项签字
- 底稿归档（调节表、计算表、审批单）
- 系统锁账，开放下期

## 制造业成本核算

### 方法选择
| 方法 | 适用 |
|---|---|
| 品种法 | 单一大批量、品种少（水泥、发电） |
| 分批法 | 订单式、单件小批（装备、模具） |
| 分步法 | 多工序连续生产（化工、纺织），分逐步结转与平行结转 |
| 作业成本法 | 间接费用占比高、产品多样 |

**一经选定不得随意变更**，变更需披露并说明影响。

### 核算流程
```
1. 归集：直接材料（领料单）、直接人工（工时/产量）、制造费用（车间归集）
2. 分配制造费用：按工时/机时/产量/工资比例，标准要稳定合理
3. 在在产品与完工产品之间分配：
   约当产量法：约当产量 = 完工数量 + 在产品数量 × 完工程度
   单位成本 = (期初成本 + 本期发生) ÷ (完工数量 + 在产品约当产量)
4. 完工转库存商品，销售转主营业务成本
```

### 制造业常见坑
- 完工程度凭感觉定 → 必须有工艺路线或实测依据
- 制造费用分配标准每月变 → 不可比
- 废品损失未单独核算，混进正常成本
- 联产品/副产品未按合理方法分摊
- 月末在产品盘亏未调整，成本虚高

## 卷二输出模板

```
一、关账日历（T-n 到 T+n，每步责任人与交付物）
二、十步清单（每步：动作 / 责任人 / 完成标准 / 状态）
三、计提清单（项目 / 金额 / 依据 / 附件）
四、成本核算表（制造业：归集 → 分配 → 约当产量 → 单位成本）
五、试算平衡与勾稽结果
六、异常与待办
七、关账检查表（可打印签字版）
```

## 卷二自检清单

- [ ] 单据截止时间已通知，系统已锁定
- [ ] 银行调节表全部账户都做了
- [ ] 暂估入库已入账，上月暂估已冲回
- [ ] 折旧摊销按规则计提（当月新增下月提）
- [ ] 应计未付费用（水电、审计费、利息）都提了
- [ ] 增值税已结转，附加税费基数正确
- [ ] 试算平衡，无异常方向余额
- [ ] 九项勾稽全过
- [ ] 制造业：完工程度有依据，分配标准与上月一致
- [ ] 底稿归档，锁账完成
