# 预算与实际差异分析

## 何时触发

用户给出预算数与实际数，问"为什么没完成""差在哪""哪个产品拖后腿""成本为什么超"。

## 需要什么输入

**必需**：预算数、实际数、同一口径的期间与单位。
**分析深度所需**：分产品/客户/区域的收入与成本明细（做量价结构分解必须有，没有就只能做总额差异）。
**可选**：上期实际、全年目标、市场均价、原材料价格指数。

**口径必须先对齐**：预算是否含税、是否含内部交易、费用分摊规则是否一致。口径不一致的差异分析全是错的。

## 分析步骤

### 第一步：总额差异
```
差异 = 实际 − 预算
差异率 = 差异 ÷ 预算
完成率 = 实际 ÷ 预算
```
标注**有利(F)/不利(U)**：收入超预算为 F，成本超预算为 U。

### 第二步：收入三因素分解

```
预算收入 = Σ(预算销量 × 预算单价)
实际收入 = Σ(实际销量 × 实际单价)

纯量差（销量差异） = (实际总销量 − 预算总销量) × 加权平均预算单价
价差（价格差异）   = Σ[(实际单价 − 预算单价) × 实际销量]
结构差（组合差异） = Σ[(实际销量 − 预算销量) × (预算单价 − 加权平均预算单价)]
```
验证：`纯量差 + 结构差 + 价差 = 总差异`，数量单位必须可比；新品零预算需另给基准。

**判断逻辑**：
- 量差为主 → 市场/销售执行问题
- 价差为负 → 降价促销、产品结构下移、渠道折扣加大
- 结构差显著 → 高毛利产品占比变化，需单独看毛利影响

### 第三步：成本差异分解（标准成本法）

```
直接材料：
  价格差异 = (实际单价 − 标准单价) × 实际用量
  用量差异 = (实际用量 − 实际产出标准用量) × 标准单价

直接人工：
  工资率差异 = (实际工资率 − 标准工资率) × 实际工时
  效率差异   = (实际工时 − 实际产出标准工时) × 标准工资率

制造费用：
  耗费差异 = 实际制造费用 − 预算制造费用
  产量差异 = (预算产量 − 实际产量) × 单位标准固定费用
```

### 第四步：费用差异
- 固定费用：看绝对额超支，责任在部门。
- 变动费用：随收入变动，先算"弹性预算"（按实际收入重算的预算），再比实际：
  ```
  弹性预算 = 固定部分 + 变动费率 × 实际收入
  真实差异 = 实际 − 弹性预算
  ```

### 第五步：定位与归因
按维度下钻，找出贡献最大的前三项：
- 产品维度：哪个 SKU 贡献了 70% 以上的不利差异
- 客户维度：大客户流失/降价/账期
- 部门维度：费用超支集中在哪个部门哪个科目
- 时间维度：是集中某月还是持续偏离（持续偏离说明预算假设错了，不是执行问题）

**关键区分**：预算假设错误 vs 执行偏差。假设错就改预算；执行偏差才追责。

### 第六步：滚动预测
```
全年预测 = 已实现 + 剩余期间预测
剩余期间预测 = 近 3 个月均值 × 季节性系数（或 剩余预算 × 趋势调整系数）
```
给出"按当前趋势全年缺口"，以及"要达成全年目标，剩余月份需月均做到 X"（判断可行性）。

## 输出模板

```
一、结论先行（三句话：差异多少、主因是什么、建议做什么）
二、总额差异表（预算 / 实际 / 差异 / 差异率 / F-U）
三、收入量价结构分解表（按产品/客户）
四、成本差异分解表（材料价格与用量、人工工资率与效率、制造费用）
五、费用弹性预算对比表
六、差异贡献度排序（Top 3 不利项，带金额与占比）
七、根因判断（假设错误 / 执行偏差 / 一次性因素）
八、改进动作（动作 + 责任人 + 时间 + 预期影响金额）
九、滚动预测与全年达成概率
十、口径与假设说明
```

## 自检清单

- [ ] 预算与实际口径一致（含税、分摊、期间）
- [ ] 三因素分解交叉验证：量差 + 价差 ≈ 总差异
- [ ] 明确标注了分解口径（是否含结构差）
- [ ] F/U 标注正确（成本超支是 U）
- [ ] 费用用弹性预算比，不是拿实际直接比原预算
- [ ] 区分了"预算假设错误"与"执行偏差"
- [ ] 改进动作有责任人与可衡量目标，不是"加强管理"
- [ ] 滚动预测说明了方法与假设
## 预算计算入口

调用 `scripts/variance_decompose.py`。三因素需纯量差+结构差+价差相加；成本效率使用 standard_qty_for_actual_output，未提供时只称静态预算差异。字段与公式见 `references/data-contract.md`。
