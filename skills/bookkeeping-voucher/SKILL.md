# 记账凭证编制

## 何时触发

用户贴一段业务描述、一张发票信息、或问"这笔怎么做账""分录怎么写"。

## 需要什么输入

**必需**：业务事实（谁、和谁、什么事、金额、含税还是不含税、日期）。
**按业务补充**：发票类型（专票/普票/其他）、合同条款（收款/履约时点）、纳税人身份（一般/小规模）、外币原币金额与汇率、是否已付款。

**信息不足时不要猜**，直接列出"缺失信息 → 影响的分录处理"，让用户补。典型缺口：
- 含税/不含税不明 → 影响税金拆分
- 一般/小规模不明 → 影响能否抵扣
- 履约时点不明 → 影响收入确认时点

## 编制步骤

### 第一步：识别业务类型
归入：采购存货 / 采购固定资产 / 费用支出 / 职工薪酬 / 销售收款 / 预收预付 / 税费 / 外币 / 研发 / 成本结转 / 年末结转 / 其他。

### 第二步：匹配模板
从 `references/entry-templates.md` 取对应模板，按实际调整科目明细与辅助核算。涉及计量口径、确认时点、会计政策或差错更正拿不准时，查 `references/cas-basics.md`，并在输出里写明所依据的准则条款名称。

### 第三步：确认五个细节

1. **票据合规**：专票才可抵扣；普票、收据、白条不得抵扣，且部分支出不得税前扣除。
2. **不得抵扣情形**：业务招待、集体福利、个人消费、简易计税与免税项目、非正常损失。
3. **税前扣除限制**：招待费（60% 且 ≤ 收入 5‰）、福利费 14%、教育经费 8% 等，超额部分要提示"汇算清缴需调整"。
4. **时点**：收入按履约义务完成（控制权转移），不按开票；费用按权责发生制，跨期要预提或待摊。
5. **资本化 vs 费用化**：固定资产达到预定可使用状态即转固；研发按阶段判定。

### 第四步：写摘要
格式：`<对方/事项> + <业务性质> + <期间>`
好例子：`采购 A 材料 3 月货款（已验收）`、`计提 2026 年 3 月工资及社保`。
坏例子：`费用`、`付款`、`往来`。

### 第五步：列附件
发票 / 合同或订单 / 验收单或入库单 / 付款回单 / 审批单 / 计算表（折旧、摊销、工资、税费）。

## 重点场景处理

### 外币业务
- 交易日用**即期汇率或近似汇率**（当月平均），一经选定前后一致。
- 期末货币性项目按期末汇率折算，差额入 `财务费用—汇兑损益`。
- 非货币性项目（历史成本计量的存货、固定资产）期末**不再折算**。
- 输出同时给原币、汇率、本位币三列，汇率来源写清楚（中间价/银行成交价/月初）。

### 研发支出
- 研究阶段、以及开发阶段不满足五项条件的：全部费用化，月末转 `管理费用—研发费用`。
- 满足资本化的：挂 `研发支出—资本化支出`，达预定用途转 `无形资产`。
- **资本化必须有证据链**：立项文件、阶段评审记录、工时记录、领料单。缺证据不要资本化，直接提示风险。

### 制造业成本
- 直接材料、直接人工计入 `生产成本`；间接费用先归集 `制造费用`，按合理标准（工时、机时、产量）分配。
- 完工转 `库存商品`，销售转 `主营业务成本`。
- 在产品约当产量法要说明完工程度依据。
- 成本核算方法（加权平均/先进先出/分批/分步）一经选定不得随意变更，变更要披露。

### 税费
- 月末结转未交增值税、计提附加税费、计提企业所得税。
- 附加税费按实际缴纳的增值税与消费税合计为基数。
- 印花税、房产税、土地使用税计入 `税金及附加`。

### 年末结转
- 损益类科目全部转 `本年利润`，再转 `利润分配—未分配利润`。
- 提取法定盈余公积（累计达注册资本 50% 可不再提）。
- 分配股利走 `利润分配—应付现金股利` → `应付股利`。

## 输出模板

```
一、业务判断（一句话说清这笔是什么、按什么原则处理）
二、会计分录
    借：科目—明细（辅助核算）      金额
      贷：科目—明细（辅助核算）    金额
    摘要：...
三、附件清单
四、税务提示（能否抵扣 / 税前扣除限额 / 需汇算调整的部分）
五、待确认事项（信息缺口与影响）
```

多笔业务用表格批量输出：

| 序号 | 日期 | 摘要 | 借方科目 | 贷方科目 | 金额 | 附件 |
|---|---|---|---|---|---|---|

## 自检清单

- [ ] 借贷平衡，金额与单据一致
- [ ] 科目用到末级，辅助核算齐全
- [ ] 含税/不含税已拆分，税率正确
- [ ] 不得抵扣的进项没有抵扣
- [ ] 摘要能让人看明白发生了什么
- [ ] 附件清单完整
- [ ] 收入时点符合履约义务，不是按开票
- [ ] 资本化有证据链，否则已费用化并提示
- [ ] 外币三要素（原币、汇率、本位币）齐全
- [ ] 缺失信息已列出，没有暗中假设
## 凭证交付边界

先用 `scripts/data_ingest.py --profile bank` 检查流水与来源；凭证模板按企业ERP字段适配。银行收付款本身不证明收入/费用确认条件。输出仅为待复核凭证，须逐笔检查重复、期间、借贷平衡、辅助核算、附件与原始行；本包未实现ERP过账或自动去重。
