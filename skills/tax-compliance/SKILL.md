# 税务管理（增值税与企业所得税）

本手册二合一：**卷一 · 增值税**（月常申报），**卷二 · 企业所得税**（年度汇算）。两卷共用一枚测算脚本 `scripts/tax_calc.py`（内置增值税、附加税费、免抵退、加计抵减、企税限额与应纳税额全链路），共用红线：比例与退税率**一律核对当期文件**，输出止于"测算 + 风险等级 + 建议复核"，不做合规背书。

**分流规则**：提"增值税 / 开票 / 进项 / 税负 / 退税 / 申报期" → 卷一；提"汇算清缴 / 企税 / 年度 / 纳税调整" → 卷二；提"个人所得税 / 个税汇算 / 专项附加扣除 / 年终奖计税" → 独立子技能 `skills/iit-filing/SKILL.md`（不在本册）。增值税月末结转与计提的分录写法在 `skills/accounting-close/SKILL.md`。

# 卷一：增值税管理（vat-management）

## 何时触发

用户给出开票明细、进项认证清单、申报表，要求核对、算税负、算退税、找异常，或准备申报底稿。

## 需要什么输入

**基础**：纳税人身份（一般/小规模）、所属期、开票明细（含税率、金额、税额、作废红冲）、进项明细（含认证/勾选状态）。
**按场景**：出口业务需报关单与离岸价、退税率；加计抵减需确认行业类别与政策适用期。
**确认项**：是否有简易计税项目、免税项目、视同销售、进项转出。

## 处理步骤

### 第一步：销项核对
1. 开票系统数据 vs 账面收入 vs 申报表，三方比对。
2. 未开票收入是否申报（预收、视同销售、无偿赠送）。
3. 作废与红冲逐笔核实原因。
4. 混合销售与兼营是否分别核算（未分别核算从高适用）。

### 第二步：进项核对
1. 勾选认证清单 vs 账面进项 vs 申报表附表二。
2. 逐笔判定不得抵扣：简易计税、免税项目、集体福利、个人消费、业务招待、非正常损失。
3. 已抵扣后改变用途的，计算进项转出：
   ```
   不得抵扣进项税额 = 当期无法划分的全部进项税额 × (当期简易计税+免税项目销售额) ÷ 当期全部销售额
   ```
4. 非正常损失按账面成本 × 适用税率转出。

### 第三步：应纳税额
```
一般计税：应纳税额 = 销项税额 − (进项税额 − 进项转出) − 上期留抵
简易计税：应纳税额 = 不含税销售额 × 征收率
合计应纳税额 = 一般计税 + 简易计税 − 加计抵减额
```
结果为负 → 形成留抵，结转下期；不得直接抵减简易计税部分。
机器测算：`scripts/tax_calc.py -i <入参.json>`（一次跑完本卷全链路）。

### 第四步：税负测算
```
增值税税负率 = 当期应纳税额 ÷ 当期不含税销售额
```
输出：本期税负、近 12 个月移动平均、与行业参考区间对比、变动原因拆解（售价、进项结构、留抵、优惠适用）。

### 第五步：出口退税（生产企业免抵退）
```
不得免征和抵扣税额 = 出口离岸价 × (征税率 − 退税率)
当期应纳税额 = 内销销项 − (当期进项 − 不得免征和抵扣税额) − 上期留抵
免抵退税额 = 出口离岸价 × 退税率
应退税额 = min(期末留抵税额, 免抵退税额)
免抵税额 = 免抵退税额 − 应退税额
```
外贸企业（免退税）：`应退税额 = 购进金额 × 退税率`。

**必须提示**：退税率须核对当期出口退税率文库；申报有期限，逾期视同内销征税；单证（报关单、发票、收汇）需齐备。

### 第六步：加计抵减
```
当期加计抵减额 = 当期可抵扣进项税额 × 加计比例
当期可抵减加计额 = 上期末余额 + 本期计提 − 本期调减
实际抵减额 = min(当期一般计税应纳税额, 当期可抵减加计额)
```
**加计比例与政策有效期必须核对当期文件**。用户没给行业类别与适用期，就写"比例待核，按 X% 试算并标注假设"，不假装确定。

### 第七步：风险预警
见 `references/vat-rules.md` 第八节指标表。逐条给"指标值 / 是否异常 / 可能原因 / 建议核查动作"，**只作线索不定性**。

## 卷一输出模板

```
一、口径声明（所属期、纳税人身份、单位、政策依据及是否已核对当期文件）
二、销项核对表（开票 / 账面 / 申报 三方差异）
三、进项核对表（认证 / 账面 / 申报 + 转出清单）
四、应纳税额计算表（分一般计税与简易计税）
五、税负率分析（本期 / 移动平均 / 行业参考 / 变动归因）
六、出口退税计算表（如适用）
七、加计抵减计算表（如适用，含比例假设标注）
八、风险清单（按严重度排序，每条带建议动作）
九、待确认事项
```

## 卷一自检清单

- [ ] 开票、账面、申报三方已比对，差异有解释
- [ ] 不得抵扣项逐笔判定过，没有漏转出
- [ ] 留抵未用于抵减简易计税
- [ ] 税负率分子分母口径一致（都用不含税销售额）
- [ ] 退税率、加计比例已标注"需核对当期文件"
- [ ] 视同销售、无偿赠送、未开票收入都考虑了
- [ ] 风险结论写成"线索 + 建议核查"，没有下定性结论
- [ ] 没有替用户承诺"这样申报没问题"

# 卷二：企业所得税汇算清缴（cit-settlement）

## 何时触发

用户给出利润表、科目余额表或费用明细，要求算应纳税所得额、做纳税调整、检查哪些支出不能扣、能不能享受优惠。

## 需要什么输入

**必需**：会计利润总额、期间、纳税人属性（是否高新/小微/西部大开发）。
**分类明细**：业务招待费、广告宣传费、职工薪酬与福利/教育/工会经费、捐赠、研发费用（费用化与资本化分开）、资产损失、罚款滞纳金、准备金、关联交易。
**历史**：以前年度亏损余额、以前年度结转的广告费与教育经费、递延所得税台账。

缺明细时，输出"调整框架 + 需补充的数据清单"，不要用总额拍一个调整额。

## 处理步骤

### 第一步：确定适用税率
一般 25%；高新 15%；小微按当期文件的三项条件判定；西部大开发 15%。
**税率选择必须写依据**，高新证书编号与有效期、小微三项指标实际值都要列。

### 第二步：会计利润 → 应纳税所得额
```
应纳税所得额 = 会计利润总额
             + 纳税调增项
             − 纳税调减项
             − 弥补以前年度亏损
             − 免税、减计收入、加计扣除等优惠
```

### 第三步：扣除限额校验
限额口径与优惠适用条件见 `references/cit-limits.md`，逐项对照，不要凭记忆填比例。
逐项列"基数 / 比例 / 限额 / 实际发生 / 可扣 / 调增或结转"：

- 业务招待费：`min(发生额×60%, 销售收入×5‰)`，差额永久调增
- 广告宣传费：一般 `收入×15%`，超支结转以后年度
- 职工福利费 `工资总额×14%`、工会经费 `×2%`、教育经费 `×8%`（教育经费超支可结转）
- 补充养老/补充医疗各 `×5%`
- 公益性捐赠：`利润总额×12%`，超支结转 3 年
- 手续费佣金：合同金额 5%（一般企业）

### 第四步：逐项调整
调增常见项：超限额三项费用、税收滞纳金与行政罚款、非公益性赞助、未经核定准备金、不征税收入对应支出、个人消费性支出、关联交易不公允部分。
调减常见项：国债利息、居民企业间股息红利、研发加计、残疾人员工资加计、以前年度结转超支、创投抵扣。

### 第五步：专项处理

**研发费用加计扣除**
- 费用化部分：`实际发生额 × 加计比例`（比例按当期文件：近年普惠口径为 100% 加计，部分重点领域企业适用更高比例，须核对当期文件）
- 资本化部分：`无形资产成本 × 加计比例`，按摊销年限加计摊销
- **负面清单行业不适用**（烟草、住宿餐饮、批发零售、房地产、租赁商务服务、娱乐业）
- 需留存备查：立项决议、研发人员名单与工时、费用分配说明、辅助账

**资产损失**
- 清单申报 vs 专项申报分类
- 会计已计提减值但损失未实际发生 → 调增
- 证据链：合同、判决/裁定、破产公告、盘点表、赔偿说明、中介报告

**股权激励**
- 等待期会计确认的费用，税法不得扣除 → 调增
- 实际行权/解禁时按"公允价 − 行权价"确认工资薪金 → 调减
- 建立时间性差异台账，逐年跟踪，同时确认递延所得税

**境外所得**
```
抵免限额 = 境内外所得按税法计算的应纳税总额 × 某国应纳税所得额 ÷ 境内外应纳税所得总额
```
超限额部分 5 年内结转；需境外完税证明。

### 第六步：亏损弥补
按年度列可弥补亏损余额，本年弥补额，剩余可结转年限（一般 5 年，高新与科技型中小 10 年）。境外亏损不得抵减境内所得。

### 第七步：风险分级
每项调整标"高/中/低"风险：
- 高：无依据的大额调减、优惠适用条件不满足、资产损失证据不足
- 中：限额临界、关联交易定价、跨境支付
- 低：常规永久性差异

限额校验与应纳税额可用 `scripts/tax_calc.py`（企税段与卷一同用一枚脚本）。

## 卷二输出模板

```
一、口径（年度、税率及依据、单位）
二、会计利润调节表（一行到底：利润总额 → 应纳税所得额 → 应纳税额）
三、纳税调整明细表
    项目 | 会计金额 | 税法金额 | 调整额 | 类型(永久/暂时) | 依据 | 风险
四、扣除限额校验表
五、研发加计 / 资产损失 / 股权激励 专项测算
六、亏损弥补表
七、优惠事项表（依据文件 + 留存备查清单）
八、风险清单与建议
九、待确认事项
```

## 卷二自检清单

- [ ] 税率有依据（证书/指标/文件）
- [ ] 招待费按"孰低"取，不是只乘 60%
- [ ] 广告费、教育经费超支正确结转，未一次性调增
- [ ] 研发加计确认不在负面清单行业
- [ ] 资产损失区分清单/专项申报
- [ ] 股权激励的时间性差异建了台账
- [ ] 亏损弥补核对年限，境外亏损未混入
- [ ] 每个比例都标注"按当期口径，需核对当期文件"
- [ ] 结论是"测算 + 风险"，不是"就这么报"
