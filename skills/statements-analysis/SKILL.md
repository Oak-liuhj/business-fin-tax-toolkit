# 财务报表编制与分析

本手册二合一：**卷一 · 报表编制**（科目余额表 → 三表），**卷二 · 分析诊断**（三表 → 结论）。两卷共用同一套勾稽标准（`references/statement-mapping.md` 第四节九项勾稽；机器校验用 `scripts/reconcile_check.py`）。

**分流规则**：用户说"出报表 / 编三表 / 报送或审计用表 / 报表平不平" → 卷一；说"这家公司怎么样 / 哪里出了问题 / 能不能投贷" → 卷二。**卷二第一步必须跑卷一的九项勾稽**——不平就回到卷一修表，不在错表上做分析。

# 卷一：报表编制（statement-prep）

## 何时触发

用户给出科目余额表（或试算平衡表、总账导出），要求出报表、检查报表平不平、或准备报送/审计用的报表。

## 需要什么输入

**必需**：科目余额表（含期初、本期发生、期末），要有科目编码与名称。
**建议**：上期已报报表（用于期初期末衔接校验）、损益类明细（用于利润表期间分析）。
**确认项**：准则（默认 CAS）、期间、单位、单体还是合并、是否已年结。

## 编制步骤

### 第一步：试算平衡
借贷合计是否相等；期初 + 本期发生 = 期末 是否成立。
**不平就停**，让用户回去查账，不要用差额硬凑一个"待处理"科目。

### 第二步：科目归类
按 `references/statement-mapping.md` 逐项映射。要点：

- **重分类**：应交税费借方余额 → 其他流动资产；应收账款贷方余额 → 预收/合同负债；预付账款贷方余额 → 应付账款。**不得以净额列示**。
- **减值准备**按抵减后净额列报。
- **一年内到期**的长期负债、长期应收款必须重分类。
- 研发费用**单列**，不并入管理费用。
- 合同资产/合同负债单独列示，不与应收/预收混同。

### 第三步：编表

**资产负债表**：按流动性排列，资产 = 负债 + 所有者权益。

**利润表**：营业收入 → 营业成本 → 税金及附加 → 期间费用 → 其他收益/投资收益/公允价值变动/减值/资产处置 → 营业利润 → 营业外收支 → 利润总额 → 所得税 → 净利润。

**现金流量表（间接法）**：
```
净利润
+ 减值准备（信用 + 资产）
+ 折旧（固定资产 + 使用权资产）
+ 无形资产摊销、长期待摊费用摊销
− 处置资产收益（+ 损失）
± 财务费用（筹资性利息）
± 存货变动（增加为负）
± 经营性应收变动（增加为负）
± 经营性应付变动（增加为正）
= 经营活动现金流净额
± 投资活动（购建资产、投资支付与收回）
± 筹资活动（借款、还款、增资、分红、付息）
= 现金及现金等价物净增加额
+ 期初余额
= 期末余额
```
**期末余额必须等于资产负债表货币资金**（若含受限资金，需在附注说明现金及现金等价物口径）。

### 第四步：九项勾稽验证

| # | 校验项 | 通过标准 |
|---|---|---|
| 1 | 资产 = 负债 + 权益 | 差额 = 0 |
| 2 | 净利润 ↔ 未分配利润变动 | 差异仅为分配与追溯调整 |
| 3 | 现金净增加额 ↔ 货币资金变动 | 差额 = 0 |
| 4 | 现金流表起点净利润 ↔ 利润表 | 一致 |
| 5 | 折旧摊销 ↔ 累计折旧/摊销贷方发生额 | 差异有说明（如处置转出） |
| 6 | 所得税费用 = 当期 + 递延 | 一致 |
| 7 | 小计 = 明细之和 | 逐栏核 |
| 8 | 本期期初 = 上期期末 | 一致 |
| 9 | 权益变动表 ↔ 资产负债表权益变动 | 一致 |

任一项不过，输出"未通过 + 差额 + 最可能的三个原因 + 建议排查顺序"，**不交半成品报表**。

### 第五步：期间对比与异动

- 环比/同比变动超 30% 的项目逐项问原因。
- 重点关注：应收账款增速 vs 收入增速、存货增速 vs 成本增速、其他应收款异常增长、在建工程长期不转固。

### 第六步：合并报表要点（如适用）

1. **合并范围**：控制为基础（权力 + 可变回报 + 影响回报），不只看持股比例。
2. **统一会计政策与期间**：子公司政策不一致须调整。
3. **抵销分录**：内部股权投资与所有者权益、内部债权债务、内部交易未实现损益、内部现金流量。
4. **少数股东权益**：单独列示于所有者权益。
5. **商誉**：仅在同控下不产生；非同控按合并成本 − 可辨认净资产公允价值份额确认，每年减值测试。

### 第七步：附注框架

按准则要求顺序：公司基本情况 → 财务报表编制基础 → 重要会计政策与会计估计 → 税项 → 合并范围 → 报表项目注释（逐项：期末余额构成、变动原因）→ 关联方及交易 → 或有事项 → 资产负债表日后事项 → 其他重要事项。

**会计估计变更、前期差错更正必须单独披露**。

## 卷一输出模板

```
一、编制口径（准则/期间/单位/单体或合并）
二、试算平衡结果
三、资产负债表
四、利润表
五、现金流量表
六、九项勾稽验证结果（逐项打勾或标差额）
七、重大变动说明（>30% 项目）
八、附注要点（如要求）
九、待确认事项清单
```

## 卷一自检清单

- [ ] 试算平衡，期初 + 发生 = 期末
- [ ] 该重分类的都重分类了（应交税费、应收/预收、一年内到期）
- [ ] 减值准备按净额列报
- [ ] 研发费用单列
- [ ] 九项勾稽全过
- [ ] 现金流量表期末现金 = 货币资金
- [ ] 单位与币种全文一致
- [ ] 未确定的事项列进"待确认"，没有偷偷假设

# 卷二：分析诊断（fin-analysis）

## 何时触发

用户给出报表（或科目余额表）并想知道"这家公司经营得怎么样""哪里出了问题""能不能投/能不能贷"。

## 需要什么输入

**必需**：资产负债表 + 利润表（至少两期，用于趋势）。
**强烈建议**：现金流量表（缺它则"现金流质量"与"净现比"只能跳过）。
**可选**：科目余额表、预算数据、行业基准。

缺两期数据时先做单期诊断，并明确写"无趋势判断"。
金额单位与币种必须确认；单位不统一（元/万元混用）会让所有比率失真。

## 分析步骤

### 第一步：勾稽与口径
先跑九项勾稽（标准见本手册卷一第四步，映射与细则见 `references/statement-mapping.md` 第四节；机器校验用 `scripts/reconcile_check.py`）。不平就停下来问用户要正确数据，**不在错表上做分析**。

### 第二步：杜邦分解

```
ROE = 净利率 × 总资产周转率 × 权益乘数
    = (净利润/营业收入) × (营业收入/总资产) × (总资产/所有者权益)
```

五因子版（把税与利息影响拆出来）：

```
ROE = 税负负担率 × 利息负担率 × 营业利润率 × 总资产周转率 × 权益乘数
    = (净利润/税前利润) × (税前利润/EBIT) × (EBIT/营业收入) × (营收/总资产) × (总资产/权益)
```

**要点**：ROE 高要问"是靠利润率、靠周转、还是靠加杠杆"。杠杆推高的 ROE 最脆弱。

### 第三步：四维指标

**偿债**
| 指标 | 公式 | 关注 |
|---|---|---|
| 流动比率 | 流动资产/流动负债 | <1 短期偿付压力 |
| 速动比率 | (流动资产−存货)/流动负债 | <0.8 偏紧 |
| 现金比率 | 货币资金/流动负债 | 最严格 |
| 资产负债率 | 负债总额/资产总额 | 结合行业 |
| 利息保障倍数 | EBIT/利息费用 | <3 警戒，<1.5 危险 |
| 有息负债/EBITDA | 有息负债/(EBIT+折旧摊销) | >4 偏高（行业相关） |

**运营**
| 指标 | 公式 |
|---|---|
| 应收账款周转率 | 营业收入/平均应收账款 |
| 应收账款周转天数(DSO) | 365/周转率 |
| 存货周转率 | 营业成本/平均存货 |
| 存货周转天数(DIO) | 365/周转率 |
| 应付账款周转天数(DPO) | 365/(营业成本/平均应付账款) |
| 现金转换周期(CCC) | DSO + DIO − DPO |
| 总资产周转率 | 营业收入/平均总资产 |

**CCC 是运营效率的总闸门**：为正说明要垫钱，为正且变长说明垫得越来越多。

**盈利**
毛利率、营业利润率、净利率、期间费用率（销售/管理/研发/财务分别看）、ROA、ROE。
毛利率下滑优先查"售价降 / 成本涨 / 产品结构变"，三者对策完全不同。

**现金流**
| 指标 | 公式 | 含义 |
|---|---|---|
| 净现比 | 经营活动现金流净额/净利润 | <1 利润含金量不足 |
| 收现比 | 销售商品收到的现金/营业收入 | <1 收入未收回 |
| 自由现金流 | 经营现金流净额 − 资本支出 | 真正可自由支配的钱 |
| 现金分红能力 | FCF/净利润 | 持续 <0 需外部输血 |

### 第四步：Z-Score 财务预警

**必须说明用的是哪个版本**，不同版本系数不可混用：

- **上市公司（制造业，Altman 1968）**
  `Z = 1.2X1 + 1.4X2 + 3.3X3 + 0.6X4 + 1.0X5`
  X1=营运资金/总资产，X2=留存收益/总资产，X3=EBIT/总资产，X4=股权市值/总负债，X5=营业收入/总资产
  判别：>2.99 安全；1.81–2.99 灰色；<1.81 危险

- **非上市公司（Z' 1983）**
  `Z' = 0.717X1 + 0.847X2 + 3.107X3 + 0.420X4 + 0.998X5`（X4 用账面权益/总负债）
  判别：>2.90 安全；1.23–2.90 灰色；<1.23 危险

- **非制造业 / 新兴市场（Z''）**
  `Z'' = 6.56X1 + 3.26X2 + 6.72X3 + 1.05X4`（去掉周转项，减少行业偏差）
  判别：>2.60 安全；1.10–2.60 灰色；<1.10 危险

**模型局限必须写出来**：为美国制造业样本拟合，对中国新经济企业判别力有限，只作参考信号，不定性为"将破产"。

### 第五步：EVA 价值创造

```
NOPAT = EBIT × (1 − 实际税率)
投入资本 = 有息负债 + 所有者权益 − 超额现金（可选调整）
EVA = NOPAT − WACC × 投入资本
```

**WACC 必须由用户提供或明确给出计算假设**：

```
WACC = E/(D+E) × Re + D/(D+E) × Rd × (1 − t)
Re = Rf + β × ERP（CAPM）
```

Rf、β、ERP、Rd、D/E 五项参数逐项列出取值与来源。**任一缺失就写"EVA 无法计算，需补充 XX"，不要拍一个 WACC 出数。**

## 卷二输出模板

```
一、总体判断（三句话：好在哪、差在哪、最紧急的一件事）
二、关键指标表（本期 / 上期 / 变动 / 行业参考 / 评价）
三、杜邦分解（找到 ROE 变动的主因）
四、四维诊断（偿债 / 运营 / 盈利 / 现金流，每维一句结论 + 证据）
五、Z-Score 预警（版本、得分、区间、局限说明）
六、EVA（参数表 + 结果，或说明无法计算的原因）
七、问题清单（按严重度排序，每条：现象 → 数据证据 → 可能原因 → 建议动作）
八、假设与口径声明
```

预算执行为什么偏，是另一件事：预算 vs 实际的量价结构归因走 `skills/budget-variance/SKILL.md`。

## 卷二自检清单

- [ ] 报表已过九项勾稽
- [ ] 全部比率用同一套单位与期间口径
- [ ] 平均余额用的是「(期初+期末)/2」，不是单期期末
- [ ] 周转天数用 365 天，全文一致
- [ ] Z-Score 版本与判别阈值匹配，已写局限
- [ ] EVA 参数全部有来源，否则标"无法计算"
- [ ] 结论都能指回具体数字
- [ ] 没有把行业特性当问题（如零售低毛利、重资产高杠杆）
