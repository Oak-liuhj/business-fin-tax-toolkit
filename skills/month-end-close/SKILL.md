# 月结管理

## 何时触发

用户要安排月末结账、写关账 SOP、检查关账是否漏项，或问"制造业成本怎么算"。

## 需要什么输入

**必需**：结账期间、主体范围、行业（是否制造业）、现有结账日与出表日要求。
**建议**：现行科目表、成本核算方法、上期关账问题清单。

## 十步关账清单

### 第 1 步：业务截止（Cut-off）
- 通知各部门单据截止时间（采购入库、报销、销售发货）
- 最后一天交易单独标记，跨期单据按权责发生制归属
- 检查期后收货/发货，避免跨期
- **系统关账前必须锁定当月凭证录入权限**

### 第 2 步：银行与资金
- 全部银行账户对账单下载，编制余额调节表
- 未达账项逐笔说明，超 30 天的重点核查
- 现金盘点，备用金核对
- 受限资金（保证金、冻结）标注，供报表披露

### 第 3 步：往来核对
- 应收/应付/其他应收应付明细账龄更新
- 与主要客户、供应商对账，差异挂"待查"
- 关联方往来单独核对
- 预收/预付按履约进度转入收入/成本

### 第 4 步：存货与成本
- 出入库单据全部过账，检查负库存
- 存货盘点（月盘或抽盘），差异调整
- 采购暂估入账（货到票未到），次月初冲回
- 制造业成本核算（见下）
- 存货跌价测试

### 第 5 步：固定资产与无形资产
- 新增资产转固（达到预定可使用状态即转，不以验收款付清为准）
- 在建工程检查，长期不转固的说明原因
- 计提折旧与摊销（注意当月新增下月计提的规则）
- 处置资产清理，净值与累计折旧同步转出

### 第 6 步：计提与摊销
必查清单：
- 职工薪酬（工资、奖金、社保、公积金、个税）
- 折旧、摊销、长期待摊费用
- 利息（含未到付息日的应计利息）、借款费用资本化
- 租金、水电、物业、审计费等已发生未取得发票的
- 销售返利、折扣、质保金
- 坏账准备（预期信用损失）
- 应交税费（增值税结转、附加税费、企业所得税、印花税、房产税）
- 预计负债（诉讼、保修）

### 第 7 步：税费
```
1. 销项与进项核对，进项转出处理
2. 结转未交增值税：借 应交税费—转出未交增值税 / 贷 未交增值税
3. 计提附加税费（以实缴增值税+消费税为基数）
4. 计提企业所得税（按当期利润与调整测算）
5. 印花税、房产税、土地使用税计提
```

### 第 8 步：损益结转与试算平衡
- 损益类科目转本年利润
- 试算平衡：借贷合计相等；期初 + 发生 = 期末
- 科目余额表导出，异常余额排查（如资产类出现贷方余额）

### 第 9 步：出表与勾稽
按 `skills/statement-prep` 出三表，跑九项勾稽。**不平不出表**。

### 第 10 步：复核与归档
- 关键科目变动分析（环比 >30% 要说明）
- 关账检查表逐项签字
- 底稿归档（调节表、计算表、审批单）
- 系统锁账，开放下期

## 制造业成本核算

### 方法选择
| 方法 | 适用 |
|---|---|
| 品种法 | 单一大批量、品种少（水泥、发电） |
| 分批法 | 订单式、单件小批（装备、模具） |
| 分步法 | 多工序连续生产（化工、纺织），分逐步结转与平行结转 |
| 作业成本法 | 间接费用占比高、产品多样 |

**一经选定不得随意变更**，变更需披露并说明影响。

### 核算流程
```
1. 归集：直接材料（领料单）、直接人工（工时/产量）、制造费用（车间归集）
2. 分配制造费用：按工时/机时/产量/工资比例，标准要稳定合理
3. 在在产品与完工产品之间分配：
   约当产量法：约当产量 = 完工数量 + 在产品数量 × 完工程度
   单位成本 = (期初成本 + 本期发生) ÷ (完工数量 + 在产品约当产量)
4. 完工转库存商品，销售转主营业务成本
```

### 制造业常见坑
- 完工程度凭感觉定 → 必须有工艺路线或实测依据
- 制造费用分配标准每月变 → 不可比
- 废品损失未单独核算，混进正常成本
- 联产品/副产品未按合理方法分摊
- 月末在产品盘亏未调整，成本虚高

## 输出模板

```
一、关账日历（T-n 到 T+n，每步责任人与交付物）
二、十步清单（每步：动作 / 责任人 / 完成标准 / 状态）
三、计提清单（项目 / 金额 / 依据 / 附件）
四、成本核算表（制造业：归集 → 分配 → 约当产量 → 单位成本）
五、试算平衡与勾稽结果
六、异常与待办
七、关账检查表（可打印签字版）
```

## 自检清单

- [ ] 单据截止时间已通知，系统已锁定
- [ ] 银行调节表全部账户都做了
- [ ] 暂估入库已入账，上月暂估已冲回
- [ ] 折旧摊销按规则计提（当月新增下月提）
- [ ] 应计未付费用（水电、审计费、利息）都提了
- [ ] 增值税已结转，附加税费基数正确
- [ ] 试算平衡，无异常方向余额
- [ ] 九项勾稽全过
- [ ] 制造业：完工程度有依据，分配标准与上月一致
- [ ] 底稿归档，锁账完成
